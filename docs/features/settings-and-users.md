# ตั้งค่า

## น้ำหนักคะแนน (`/settings/scoring-weights`)

**ใครดูได้**: ทุกคน · **ใครแก้ได้**: ผู้จัดการเท่านั้น

ปรับน้ำหนัก (0–100) ของ 5 เกณฑ์ที่ใช้คำนวณคะแนนรวม พร้อมประวัติการแก้ไข

| เกณฑ์ | น้ำหนักเริ่มต้นที่ระบบเสนอ |
|---|---|
| ยอดขาย vs เป้า | 50% |
| ลูกค้าใหม่ vs เป้า | 15% |
| ยอดตามกลุ่มสินค้า vs เป้า | 15% |
| การรักษาลูกค้า (active / ไม่ churn) | 10% |
| ความสม่ำเสมอของยอด | 10% |

⚠️ ตัวเลขน้ำหนักเริ่มต้นข้างต้นอ้างอิงจากเอกสารความต้องการ ปรับได้ทุกเมื่อในหน้านี้ — ให้ยึดค่าที่แสดงจริงในระบบเป็นหลัก

## ค่าคงที่การประเมิน (`/settings/evaluation`)

**ใครดูได้**: ทุกคน · **ใครแก้ได้**: ผู้จัดการเท่านั้น

ค่าคงที่ของระบบ (พารามิเตอร์ที่ใช้ในการคำนวณ/AI/ศักยภาพ/ตัวช่วยตั้งเป้า) — แก้ผ่านฟอร์มเดียวกับที่ใช้ดู

## น้ำหนักระดับ รพ. (`/settings/tier-weights`)

**ใครเข้าได้**: ผู้จัดการเท่านั้น

น้ำหนักตามระดับโรงพยาบาล (A/S/M1/M2/F1/F2/F3) ที่ใช้ในการคำนวณศักยภาพพื้นที่และเป้า — หากยังไม่มีทะเบียนโรงพยาบาลที่มีข้อมูลระดับ หน้านี้จะแสดงข้อความ "ยังไม่มีระดับโรงพยาบาลในทะเบียน — นำเข้าไฟล์ทะเบียนก่อนจึงจะมีระดับให้ตั้งค่า"

## จัดการผู้ใช้งาน (`/users`)

**ใครเข้าได้**: ผู้จัดการเท่านั้น

- สร้างบัญชีผู้ใช้ใหม่ (ระบบสร้างรหัสผ่านชั่วคราวให้)
- แก้ไขข้อมูลบัญชี
- รีเซ็ตรหัสผ่าน (แสดงรหัสผ่านชั่วคราวใหม่)
- เปิด/ปิดการใช้งานบัญชี (ต้องยืนยันก่อนทำ)
- กรองตามบทบาท หรือกรองบัญชีที่ยังไม่ผูกกับข้อมูลพนักงานขาย

📷 Screenshot Required: หน้าจัดการผู้ใช้งาน
