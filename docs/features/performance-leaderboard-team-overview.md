# ผลงาน / Leaderboard / ภาพรวมทีม

## ผลงานรายบุคคล (`/performance/individual`)

**ใครเข้าได้**: ทุกคน (ค่าเริ่มต้นคือดูของตัวเอง — ผู้จัดการ/supervisor ต้องเลือกคนอื่นเองถ้าต้องการดู)

รายงานผลงานเต็มรูปแบบของพนักงานขายหนึ่งคนหนึ่งรอบ (เดือน/ไตรมาส/ปี):

- เป้าเทียบผลจริง
- ทุก KPI พร้อมคะแนนรวม
- เปรียบเทียบกับรอบก่อนหน้า (ดีขึ้น/แย่ลง)
- คำแนะนำ AI (จุดแข็ง/จุดที่ควรพัฒนา) — ถ้ามีคนสร้างไว้แล้ว
- ปุ่ม Export

📷 Screenshot Required: หน้าผลงานรายบุคคล

## Leaderboard (`/leaderboard`)

**ใครเข้าได้**: ทุกคน — แต่บางฟิลด์ถูกจำกัดฝั่งเซิร์ฟเวอร์ตามสิทธิ์

จัดอันดับ **ระดับเขต** (ไม่ใช่รายบุคคล) ด้วยคะแนนรวมของเขต:

- ทุกคนเห็น**แถวครบทุกเขต**และอันดับจริง
- สลับเกณฑ์การจัดอันดับได้: คะแนนรวม / % ทำได้ตามเป้า / ยอดขาย / ลูกค้าใหม่
- เลือกช่วงเวลาได้: เดือน / ไตรมาส / ปี
- Export

**กดดูรายบุคคลในเขต (drill-down)** — สิทธิ์ต่างกันตามบทบาท:

| บทบาท | กดดูรายบุคคลในเขตไหนได้ |
|---|---|
| ผู้จัดการ | ทุกเขต |
| Sales Supervisor | เฉพาะเขตที่ตัวเองเป็น supervisor |
| พนักงานขายทั่วไป | กดดูรายบุคคลของคนอื่นไม่ได้เลย |

⚠️ เขตที่ไม่มีผู้ดูแล จะขึ้นข้อความ "ยังไม่มีผู้ดูแล" แต่ยังจัดอันดับตามปกติ — ไม่ใช่ข้อผิดพลาด

📷 Screenshot Required: หน้า Leaderboard ระดับเขต และ modal drill-down รายบุคคล

## ภาพรวมทีม (`/reports/team-overview`)
