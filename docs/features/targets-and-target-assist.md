# เป้าหมาย

## ตั้งเป้า (`/targets`)

**ใครดูได้**: ทุกคน · **ใครแก้ได้**: ผู้จัดการเท่านั้น

ตารางเป้ารายเดือนของแต่ละพนักงานขาย:

- แก้เป้าทีละคน หรือ **คัดลอกเป้าเดือนก่อน**มาใช้ซ้ำ
- ดูรายละเอียดเป้าแยกตามกลุ่มสินค้า
- ทุกครั้งที่แก้เป้า ระบบบันทึก**ประวัติการแก้ไข** — ใครแก้ เมื่อไหร่ จากเท่าไหร่เป็นเท่าไหร่ ดูได้ที่หน้า "ประวัติการแก้ไข" ของแต่ละเป้า

📷 Screenshot Required: ตารางตั้งเป้ารายเดือน

## เป้ารายเขต (`/territories/targets`)

**ใครดูได้**: ทุกคน · **ใครแก้ได้**: ผู้จัดการเท่านั้น

ตารางเดียวกันแต่กำหนดเป้าที่ระดับเขตแทนรายคน

## ตัวช่วยตั้งเป้า (`/target-assist`)

**ใครเข้าได้**: ผู้จัดการเท่านั้น

เสนอตัวเลขเป้าตั้งต้นโดยคำนวณจากประวัติยอดขายจริง — ผู้จัดการแก้ทับได้เสมอ:

- สลับโหมด **SUGGEST** (เสนอเป้าใหม่) / **REBALANCE** (จัดสรรใหม่)
- ปรับอัตราการเติบโตที่ใช้คำนวณได้เอง (0–999.999%)
- **รับข้อเสนอ (accept)** ตัวเลขที่ระบบเสนอ
- **ตัดดีล (cut)** ที่ผิดปกติออกจากฐานการคำนวณ และ **คืนดีล (reinstate)** ภายหลังได้ถ้าต้องการ

📷 Screenshot Required: หน้าตัวช่วยตั้งเป้า พร้อมตัวเลขที่ระบบเสนอ

## KPI รายเขต (`/territory-kpi`)

**ใครเข้าได้**: ทุกคน

ตาราง KPI ระดับเขตและระดับกลุ่มเขต พร้อมส่วนกระทบยอด (reconciliation) — กดดูรายละเอียดที่มาของแต่ละตัวเลขได้ Export ได้
