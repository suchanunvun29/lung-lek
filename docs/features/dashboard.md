# ภาพรวม (Dashboard)

**เส้นทาง**: `/dashboard` · **ใครเข้าได้**: ทุกคน (ผู้จัดการต้องเลือกว่าจะดูของใครก่อน — ระบบไม่เลือกให้อัตโนมัติ)

หน้าแรกที่พาไปหลังเข้าสู่ระบบ แสดงภาพรวมผลงานของพนักงานขายหนึ่งคน

## สิ่งที่แสดงบนหน้านี้

- คะแนนรวม เทียบเป้า และ **เหลืออีกเท่าไหร่ถึงเป้า** สำหรับเดือนนี้/ไตรมาสนี้/ปีนี้
- แนวโน้มยอดขายรายเดือนย้อนหลัง
- สัดส่วนยอดขายตามกลุ่มสินค้าและตามโรงพยาบาล
- คะแนนแยกราย KPI ทั้ง 5 เกณฑ์ พร้อมสถานะเทียบเป้าและเทียบค่าเฉลี่ยทีม
- รายการ "สิ่งที่ต้องดำเนินการ" (action needed)
- ส่วนคำแนะนำ AI (พับเก็บได้) หากมีคนสร้างไว้แล้ว

📷 Screenshot Required: หน้า Dashboard พร้อมการ์ดคะแนนและกราฟแนวโน้ม

## การใช้งาน

- **พนักงานขายทั่วไป**: เห็น Dashboard ของตัวเองเท่านั้น
- **ผู้จัดการ**: ต้องเลือกพนักงานขายที่ต้องการดูก่อน (ผ่านตัวสลับ) — ไม่มีการเลือก "คนแรกในรายชื่อ" ให้อัตโนมัติ
- กดที่ตัวชี้วัดแต่ละตัวเพื่อดูรายละเอียดที่มาของตัวเลข (drill-down)
- หากบัญชีของคุณยังไม่ถูกผูกกับข้อมูลพนักงานขาย ระบบจะแสดงข้อความแจ้งเตือนแทนข้อมูล — ดู [แก้ไขปัญหา](/troubleshooting/)
