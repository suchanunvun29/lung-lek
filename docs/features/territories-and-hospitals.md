# พื้นที่และลูกค้า

## จัดการเขต (`/territories`)

**ใครดูได้**: ทุกคน · **ใครแก้ได้**: ผู้จัดการเท่านั้น

- สร้างเขตใหม่ / เปิด-ปิดการใช้งานเขต
- มอบหมาย/ถอนสิทธิ์ **supervisor** ให้พนักงานขายคนหนึ่งในเขตหนึ่ง (พร้อมวันที่มีผล)
- จัดกลุ่มเขต (territory groups)

📷 Screenshot Required: หน้าจัดการเขตและฟอร์มมอบหมาย supervisor

## ย้าย รพ. เข้าเขต (`/territories/moves`)

**ใครเข้าได้**: ผู้จัดการเท่านั้น

- ย้ายโรงพยาบาลทีละแห่งด้วยการค้นหา
- ย้ายยกจังหวัด (bulk move) — มีขั้นยืนยันก่อนทำจริง

## รพ. ที่ยังไม่ผูกเขต (`/territories/unassigned`)

**ใครเข้าได้**: ผู้จัดการเท่านั้น

รายการโรงพยาบาลที่ยังไม่มีเขต — มอบหมายทีละแห่งหรือเลือกหลายแห่งมอบหมายพร้อมกัน (bulk) ระบบแสดงจำนวนที่สำเร็จ/ไม่สำเร็จหลังทำ

## พื้นที่รับผิดชอบ (`/my-territory`)

**ใครเข้าได้**: ทุกคน

โรงพยาบาลในเขตที่ผูกกับคุณ (หรือคนที่คุณเลือกดู หากมีสิทธิ์) แบ่งเป็น 3 แท็บ:

- **ขายแล้ว** — ปิดดีลไปแล้วในเขตนี้
- **หายไป** (churn) — เคยขายแต่ไม่มีรายการในช่วงหลัง
- **ยังไม่เคยขาย** — โอกาสที่ยังไม่ได้ทำ

กรองตามพนักงานขาย/กลุ่มสินค้า/จังหวัด/top-N ได้ · Export ได้ทุกแท็บ

📷 Screenshot Required: หน้าพื้นที่รับผิดชอบ 3 แท็บ

## ทะเบียนโรงพยาบาล (`/hospital-registry`)

**ใครเข้าได้**: ผู้จัดการเท่านั้น

ทะเบียนกลางของโรงพยาบาลพร้อมข้อมูลศักยภาพ (จำนวนเตียง ประเภทโรงพยาบาล ฯลฯ):

- ค้นหา/กรองตามจังหวัด/เขต แบ่งหน้าผลลัพธ์
- แก้ **ค่าปรับศักยภาพ** รายแถว — ⚠️ ใส่ค่า `0` หมายถึง "ไม่นำโรงพยาบาลนี้เข้าการคำนวณศักยภาพเลย" ไม่ใช่แปลว่ายังไม่ได้กรอก
- อัปโหลดไฟล์ทะเบียนใหม่ — ระบบรายงานจำนวนที่เพิ่ม/แก้ไข/ข้าม และจำนวนที่จับคู่กับข้อมูลเดิมได้
