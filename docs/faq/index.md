# คำถามที่พบบ่อย

## ทำไมฉันไม่เห็นเมนูบางเมนู?

เมนูที่ไม่ปรากฏในแถบด้านข้างของคุณคือเมนูที่สงวนไว้สำหรับผู้จัดการเท่านั้น (เช่น นำเข้าข้อมูล, ทะเบียนโรงพยาบาล, จัดการผู้ใช้งาน, ตัวช่วยตั้งเป้า) — ดูรายการทั้งหมดที่ [สิทธิ์การใช้งาน](/roles/)

## ทำไม Leaderboard ไม่แสดงตัวเลขบางช่องของเขตอื่น?

เป็นความตั้งใจของระบบ — คุณเห็น**อันดับและชื่อทุกเขต**เหมือนกันหมด แต่รายละเอียดตัวเลข (ยอดขาย % ถึงเป้า คะแนนแยกราย KPI) ของเขตที่คุณไม่ได้เป็นสมาชิก/supervisor จะถูกซ่อนฝั่งเซิร์ฟเวอร์ ดู [ผลงาน / Leaderboard / ภาพรวมทีม](/features/performance-leaderboard-team-overview)

## ทำไมกดสั่งสร้างคำแนะนำ AI ไม่ได้?

พนักงานขายทั่วไปเปิด**อ่าน**คำแนะนำที่สร้างไว้แล้วได้ แต่**สั่งสร้างเองไม่ได้** — ต้องให้ผู้จัดการ หรือ supervisor ของเขตคุณ เป็นผู้สั่งสร้างให้ ดู [สั่งสร้างคำแนะนำ AI](/tasks/generate-ai-coaching)

## แก้ไขเป้าย้อนหลังได้ไหม?

ได้ — ผู้จัดการแก้เป้าระหว่างปีได้ และทุกครั้งที่แก้ ระบบจะบันทึกประวัติไว้ (ใครแก้ เมื่อไหร่ จากเท่าไหร่เป็นเท่าไหร่) ดูได้ที่หน้าประวัติการแก้ไขของแต่ละเป้า

## ทำไมตัวเลข "ขายไม่ได้เลย" ของสินค้าดูไม่ครบ?

ทะเบียนสินค้าที่ใช้เทียบในรอบนี้สร้างจากสินค้าที่เคยปรากฏในประวัติการขายเท่านั้น ไม่ใช่แคตตาล็อกสินค้าทั้งหมดของบริษัท — สินค้าที่ไม่มีเขตไหนเคยขายได้เลยจะไม่ปรากฏในรายการนี้ ดู [ข้อมูลการขาย](/features/sales-data-and-master-data#อันดับสินค้าตามเขต-territory-products)

## กดปุ่ม "รวม" ในหน้ายืนยันชื่อซ้ำแล้วย้อนกลับได้ไหม?

ไม่ได้ — การรวมชื่อ (MERGED) เป็นการลบระเบียนซ้ำถาวร ระบบมีกล่องยืนยันก่อนทำเพราะเป็นการดำเนินการที่แก้คืนไม่ได้ ให้ตรวจสอบให้แน่ใจก่อนกดยืนยัน ดู [ยืนยันชื่อที่ซ้ำกัน](/tasks/resolve-name-duplicates)
