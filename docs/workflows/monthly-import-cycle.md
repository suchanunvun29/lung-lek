# รอบนำเข้าข้อมูลประจำเดือน

ภาพรวมของขั้นตอนทั้งหมดที่ผู้จัดการมักทำในแต่ละเดือนเมื่อได้รับไฟล์ยอดขายใหม่ — แต่ละขั้นมีรายละเอียดในหน้าคู่มืองานของตัวเอง

```
1. นำเข้าไฟล์ Excel ยอดขายเดือนนี้
        ↓
2. ตรวจผลการนำเข้า (สำเร็จ/ข้าม/มีปัญหากี่แถว)
        ↓
3. มีชื่อซ้ำที่คลุมเครือหรือไม่?
        ├─ มี → ยืนยันชื่อที่ซ้ำกัน (รวม/แยกไว้)
        └─ ไม่มี → ข้ามไปขั้นถัดไป
        ↓
4. มีโรงพยาบาลใหม่ที่ยังไม่มีเขตหรือไม่?
        ├─ มี → จับคู่เข้าเขต
        └─ ไม่มี → ข้ามไปขั้นถัดไป
        ↓
5. ตรวจ/ปรับเป้าของเดือนนี้ (หรือใช้ตัวช่วยตั้งเป้า)
        ↓
6. ดูภาพรวมทีม → สั่งสร้างคำแนะนำ AI ให้คนที่ต้องการความช่วยเหลือ
        ↓
7. Export รายงานไปใช้คุยประเมิน
```

## รายละเอียดแต่ละขั้น

1. [นำเข้าข้อมูลการขายรายเดือน](/tasks/import-monthly-sales)
2. ดูผลที่ [ประวัติการนำเข้า](/features/sales-data-and-master-data#ประวัติการนําเข้า-import-batches)
3. [ยืนยันชื่อที่ซ้ำกัน](/tasks/resolve-name-duplicates)
4. [จัดการเขตและ supervisor](/tasks/manage-territories) → ส่วนจับคู่โรงพยาบาลที่ยังไม่มีเขต
5. [ตั้ง/แก้เป้าให้พนักงานขาย](/tasks/set-targets)
6. [สั่งสร้างคำแนะนำ AI](/tasks/generate-ai-coaching)
7. [Export รายงาน](/tasks/export-reports)
