# การแทนที่/ลบข้อมูลตามงวด

**สิทธิ์ที่ต้องใช้**: ผู้จัดการเท่านั้น — เป็นการดำเนินการที่กระทบข้อมูลจริงและ**ลบข้อมูลถาวร ไม่ใช่ซ่อนไว้** จึงมีขั้นยืนยันหลายชั้น

## แทนที่ข้อมูลทั้งงวด (REPLACE_PERIOD)

ใช้เมื่อไฟล์ที่จะนำเข้าใหม่ควรแทนที่ข้อมูลเดิมของงวดนั้นทั้งหมด แทนที่จะเพิ่มต่อ:

1. ที่หน้า [นำเข้าข้อมูล](/tasks/import-monthly-sales) เลือกโหมด **REPLACE_PERIOD**
2. เลือกงวดที่ต้องการแทนที่
3. ระบบ**บังคับให้ดูตัวอย่างผลลัพธ์ (dry-run) ก่อนเสมอ** — ไม่สามารถแทนที่จริงในคำขอเดียวได้
4. ตรวจตัวอย่างให้แน่ใจ แล้วจึงกดยืนยันแทนที่จริง

## ลบข้อมูลตามงวดแบบเดี่ยว (PERIOD_DELETE)

ใช้เมื่อต้องการลบข้อมูลของงวดหนึ่งออกโดยไม่นำเข้าไฟล์ใหม่แทน:

1. ในส่วนลบข้อมูลตามงวด (โซนที่แยกไว้ต่างหาก เพราะเป็นการทำลายข้อมูล)
2. **พิมพ์งวดที่ต้องการลบซ้ำเพื่อยืนยัน** ก่อนระบบยอมให้ไปต่อ (ป้องกันลบผิดงวดโดยไม่ตั้งใจ)
3. ดูตัวอย่างผลลัพธ์ (dry-run) ก่อนยืนยัน
4. กดยืนยันลบจริง

## ⚠️ ข้อควรระวัง

- การลบเป็นการลบจริง (hard delete) ไม่ใช่ soft-delete — กู้คืนไม่ได้หลังยืนยัน
- ตรวจสอบให้แน่ใจว่าเลือกงวดถูกต้องก่อนพิมพ์ยืนยัน
