# วิธีตั้ง/แก้เป้าให้พนักงานขาย

**สิทธิ์ที่ต้องใช้**: ผู้จัดการเท่านั้น (พนักงานขายดูได้แต่แก้ไม่ได้)

## ตั้งเป้ารายเดือนรายคน

1. เข้าเมนู **ตั้งเป้า** (`/targets`)
2. เลือกเดือน/ปีที่ต้องการตั้งเป้า
3. กรอกเป้าให้แต่ละคนในตาราง หรือกด **คัดลอกเป้าเดือนก่อน** เพื่อใช้ตัวเลขเดิมเป็นจุดเริ่มต้น
4. แก้ทับตัวเลขที่ต้องการเปลี่ยน
5. บันทึก

📷 Screenshot Required: ตารางตั้งเป้ารายเดือน

## ตั้งเป้าแยกตามกลุ่มสินค้า

กดที่เป้าของแต่ละคนเพื่อเปิดรายละเอียดเป้าตามกลุ่มสินค้า (ไม่บังคับต้องตั้งครบทุกกลุ่ม)

## ตั้งเป้าระดับเขตแทน

หากต้องการตั้งเป้าที่ระดับเขตแทนรายคน ใช้เมนู **เป้ารายเขต** (`/territories/targets`) — วิธีใช้งานเหมือนกับหน้าตั้งเป้ารายคน

## ดูประวัติการแก้ไขเป้า

ทุกเป้าจะมีลิงก์ไปหน้า **ประวัติการแก้ไข** (`/targets/[id]/revisions`) แสดงว่าใครแก้ เมื่อไหร่ จากเท่าไหร่เป็นเท่าไหร่ — ใช้เพื่อย้อนดูว่าตอนประเมินผลรอบนั้นเป้าที่ใช้จริงคือเท่าไหร่

## ใช้ตัวช่วยตั้งเป้าแทนการกรอกเอง

หากต้องการให้ระบบเสนอตัวเลขเป้าจากประวัติยอดขาย ใช้เมนู [ตัวช่วยตั้งเป้า](/features/targets-and-target-assist#ตัวช่วยตั้งเป้า-target-assist) แทน
