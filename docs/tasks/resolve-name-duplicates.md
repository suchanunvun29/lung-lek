# วิธียืนยันชื่อที่ซ้ำกัน

**สิทธิ์ที่ต้องใช้**: ผู้จัดการเท่านั้น

เมื่อนำเข้าข้อมูล ระบบอาจพบชื่อโรงพยาบาลหรือพนักงานขายที่ **สะกดคล้ายกันแต่ไม่เหมือนเป๊ะ** (เช่น เว้นวรรคต่างกัน, ตัวพิมพ์ใหญ่-เล็ก) แล้วพักไว้ในคิว **ยืนยันชื่อที่ซ้ำกัน** (`/name-reviews`) ให้ผู้จัดการตัดสินใจ แทนที่จะสร้างระเบียนใหม่เงียบ ๆ

## ขั้นตอน

1. เข้าเมนู **ยืนยันชื่อที่ซ้ำกัน**
2. เลือกแท็บที่ต้องการตรวจ: **โรงพยาบาล** หรือ **พนักงานขาย** (มีแท็บกฎแบ่งเครดิตของพนักงานขายแยกด้วย)
3. สำหรับแต่ละรายการ เลือกหนึ่งใน:
   - **รวม (MERGED)** — ยืนยันว่าเป็นรายเดียวกัน ระบบจะย้ายข้อมูลไปรวมและ**ลบระเบียนซ้ำถาวร** ต้องกดยืนยันอีกครั้งในกล่องโต้ตอบเพราะเป็นการลบข้อมูลจริง
   - **แยกไว้ (KEPT_SEPARATE)** — ยืนยันว่าเป็นคนละรายจริง คลิกเดียวจบ ไม่ลบข้อมูลใด ๆ
4. การตัดสินใจจะถูกจดจำไว้ ใช้กับการนำเข้าไฟล์ครั้งถัดไปโดยอัตโนมัติ — ไม่ต้องตอบคำถามเดิมซ้ำทุกเดือน

📷 Screenshot Required: คิวยืนยันชื่อซ้ำ พร้อมปุ่มรวม/แยกไว้

## กฎแบ่งเครดิต (พนักงานขาย)

หากมีชื่อพนักงานขาย 2 คนอยู่ในช่องเดียวกัน (แบ่งเครดิตดีลร่วมกัน) หน้านี้มีแท็บสำหรับตั้งสัดส่วนแบ่งเครดิต — **ผลรวมสัดส่วนของทุกคนในรายการต้องเท่ากับ 100% เสมอ**

## ⚠️ ก่อนกด "รวม"

การกด **รวม (MERGED)** เป็นการลบข้อมูลถาวรและมีผลย้อนหลัง — ตัวเลขที่เคยเห็นบนหน้าจออื่น (เช่น Leaderboard, ค่าเฉลี่ยทีม) อาจเปลี่ยนไปหลังรวมเสร็จ เพราะตัวเลขชุดเดิมนับซ้ำอยู่ ตรวจให้แน่ใจก่อนกดยืนยัน
