# วิธีจัดการเขตและมอบหมาย supervisor

**สิทธิ์ที่ต้องใช้**: ผู้จัดการเท่านั้น

## สร้างเขตใหม่

1. เข้าเมนู **จัดการเขต** (`/territories`)
2. กดสร้างเขตใหม่ กรอกชื่อเขต
3. บันทึก

## มอบหมาย/ถอนสิทธิ์ supervisor

1. ในหน้าจัดการเขต เลือกเขตที่ต้องการ
2. เลือกพนักงานขายที่ต้องการตั้งเป็น supervisor พร้อมวันที่มีผล
3. บันทึก — คนนั้นจะได้สิทธิ์เห็นข้อมูลรายบุคคลของทุกคนในเขตนี้ และสั่งสร้างคำแนะนำ AI ให้คนในเขตนี้ได้ (ดู [สิทธิ์การใช้งาน](/roles/))
4. หากต้องการถอนสิทธิ์ ใช้ปุ่มถอน (มีกล่องยืนยันก่อนทำ)

📷 Screenshot Required: ฟอร์มมอบหมาย supervisor

## ย้ายโรงพยาบาลไปเขตอื่น

1. เข้าเมนู **ย้าย รพ. เข้าเขต** (`/territories/moves`)
2. ค้นหาโรงพยาบาลที่ต้องการย้าย เลือกเขตปลายทาง แล้วยืนยัน — หรือ
3. ใช้ **ย้ายยกจังหวัด** หากต้องการย้ายโรงพยาบาลทั้งจังหวัดในครั้งเดียว (มีกล่องยืนยันก่อนทำจริง เพราะกระทบหลายรายการพร้อมกัน)

## จับคู่โรงพยาบาลที่ยังไม่มีเขต

1. เข้าเมนู **รพ. ที่ยังไม่ผูกเขต** (`/territories/unassigned`)
2. มอบหมายทีละแห่ง หรือเลือกหลายแห่งแล้วมอบหมายพร้อมกัน (bulk)
3. ระบบแสดงจำนวนที่สำเร็จ/ไม่สำเร็จหลังทำ
