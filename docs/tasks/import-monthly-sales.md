# วิธีนำเข้าข้อมูลการขายรายเดือน

**สิทธิ์ที่ต้องใช้**: ผู้จัดการเท่านั้น

## ขั้นตอน

1. เข้าเมนู **นำเข้าข้อมูล** (`/import`)
2. เลือกไฟล์ Excel (.xlsx) ที่ต้องการนำเข้า — ไฟล์ต้องไม่เกิน 20MB และอ่านเฉพาะชีตแรกของไฟล์
3. เลือกโหมดการนำเข้า:
   - **APPEND** — เพิ่มข้อมูลต่อจากที่มีอยู่
   - **REPLACE_PERIOD** — แทนที่ข้อมูลของงวดเดิมทั้งหมด (ต้องผ่านขั้น dry-run ก่อนเสมอ ดูด้านล่าง)
4. เลือกงวด (เดือน/ปี) ที่ไฟล์นี้เป็นของ
5. กดอัปโหลด
6. ตรวจสอบผลการนำเข้า: นำเข้ากี่แถวสำเร็จ ข้ามกี่แถว มีปัญหากี่แถวและเพราะอะไร

📷 Screenshot Required: หน้าอัปโหลดไฟล์พร้อมตัวเลือกโหมด และหน้าสรุปผลการนำเข้า

## ถ้าเลือกโหมด REPLACE_PERIOD

ระบบ**บังคับให้ดู dry-run (ตัวอย่างผลลัพธ์)ก่อนเสมอ** จะแทนที่ข้อมูลในคำขอเดียวไม่ได้ — ตรวจตัวอย่างให้แน่ใจก่อนกดยืนยันจริง

## หลังนำเข้าเสร็จ

ระบบแสดงรายการ "ขั้นตอนถัดไป" ที่แนะนำ ซึ่งอาจรวมถึง:

- เปิดดูรายละเอียดที่ [ประวัติการนำเข้า](/features/sales-data-and-master-data#ประวัติการนําเข้า-import-batches)
- ไป [ยืนยันชื่อที่ซ้ำกัน](/tasks/resolve-name-duplicates) หากพบชื่อโรงพยาบาล/พนักงานขายที่คลุมเครือ
- ไป [รพ. ที่ยังไม่ผูกเขต](/features/territories-and-hospitals#รพ-ที่ยังไม่ผูกเขต-territories-unassigned) หากมีโรงพยาบาลใหม่ที่ยังไม่มีเขต
- ไป [ตั้ง/แก้เป้าให้พนักงานขาย](/tasks/set-targets) สำหรับงวดใหม่

## กันข้อมูลซ้ำ

ระบบกันการนับยอดซ้ำสองรอบโดยอัตโนมัติหากอัปโหลดไฟล์ที่มีรายการเดิมซ้ำเข้ามา

## ⚠️ ต้องตรวจสอบเพิ่มเติม

- โครงสร้างคอลัมน์ไฟล์ Excel ที่ระบบรองรับ (`Hospital Name · Salesman · Inv Date · Year · Month · Inv No. · Po NO. · Product type · Product Name · Lot · Exp · Province · Qty · Price · Amount · Vat · Total`) มาจากเอกสารความต้องการทางธุรกิจ — ให้ยืนยันกับไฟล์ template จริงที่ใช้งานก่อนอัปโหลดครั้งแรก
