# วิธี Export รายงาน

**สิทธิ์ที่ต้องใช้**: ขึ้นกับหน้าที่กำลังดู — ทุกคน Export ข้อมูลที่ตัวเองมีสิทธิ์เห็นได้อยู่แล้ว

หน้าจอต่อไปนี้มีปุ่ม **Export** สำหรับดาวน์โหลดข้อมูลที่กำลังแสดงอยู่:

- [ผลงานรายบุคคล](/features/performance-leaderboard-team-overview#ผลงานรายบุคคล-performance-individual) — รายงาน 1 หน้าต่อ 1 คนต่อ 1 รอบ เหมาะสำหรับเอาไปใช้ในที่ประชุมประเมิน
- [ภาพรวมทีม](/features/performance-leaderboard-team-overview#ภาพรวมทีม-reports-team-overview) — ภาพรวมทั้งทีมในไฟล์เดียว
- [Leaderboard](/features/performance-leaderboard-team-overview#leaderboard-leaderboard)
- [พื้นที่รับผิดชอบ](/features/territories-and-hospitals#พื้นที่รับผิดชอบ-my-territory) (ทุกแท็บ)
- [อันดับสินค้าตามเขต](/features/sales-data-and-master-data#อันดับสินค้าตามเขต-territory-products)
- [KPI รายเขต](/features/targets-and-target-assist#kpi-รายเขต-territory-kpi)

## ขั้นตอนทั่วไป

1. เปิดหน้าที่ต้องการ Export
2. ตั้งตัวกรอง/ช่วงเวลาที่ต้องการให้ตรงกับข้อมูลที่จะ Export ก่อน (ไฟล์ที่ได้จะตรงกับสิ่งที่กำลังแสดงบนหน้าจอ)
3. กดปุ่ม Export
4. ไฟล์จะถูกดาวน์โหลดลงเครื่อง

📷 Screenshot Required: ปุ่ม Export บนหน้าผลงานรายบุคคล

## ⚠️ ต้องตรวจสอบเพิ่มเติม

- รูปแบบไฟล์ที่ Export ออกมา (Excel/PDF/CSV) ไม่ได้ตรวจยืนยันในรอบการสำรวจนี้ — ให้ดูจากไฟล์ที่ดาวน์โหลดจริงเมื่อกดใช้งาน
