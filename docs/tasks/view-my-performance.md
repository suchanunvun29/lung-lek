# วิธีดูผลงานของตัวเอง

**สิทธิ์ที่ต้องใช้**: ทุกคน — หน้านี้แสดงข้อมูลของตัวเองเป็นค่าเริ่มต้นเสมอ

## ดูภาพรวมเร็ว ๆ

1. เปิด [Dashboard](/features/dashboard) (หน้าแรกหลังเข้าสู่ระบบ)
2. ดูยอดสะสมเดือนนี้/ไตรมาสนี้/ปีนี้เทียบเป้า และเหลืออีกเท่าไหร่ถึงเป้า
3. กดที่ตัวชี้วัดใดก็ได้เพื่อดูรายละเอียดที่มาของตัวเลข

## ดูรายละเอียดครบทุก KPI

1. เปิด [ผลงานรายบุคคล](/features/performance-leaderboard-team-overview#ผลงานรายบุคคล-performance-individual)
2. ดูคะแนนรวม คะแนนแยกราย KPI ทั้ง 5 เกณฑ์ และเทียบกับรอบก่อนหน้า
3. อ่านคำแนะนำจุดแข็ง/จุดที่ควรพัฒนา (AI) หากผู้จัดการ/supervisor สร้างไว้ให้แล้ว — ดู [สั่งสร้างคำแนะนำ AI](/tasks/generate-ai-coaching) (พนักงานขายทั่วไปสั่งสร้างเองไม่ได้)

## เปรียบเทียบกับทีม

1. เปิด [Leaderboard](/features/performance-leaderboard-team-overview#leaderboard-leaderboard)
2. ดูอันดับเขตของคุณเทียบกับเขตอื่น (เห็นแถวครบทุกเขต)
3. หากคุณเป็น supervisor ของเขตใด กดดูรายบุคคลในเขตนั้นได้ — เขตอื่นและพนักงานขายทั่วไปดูรายบุคคลของคนอื่นไม่ได้ ดู [สิทธิ์การใช้งาน](/roles/)
