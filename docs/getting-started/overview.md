# ระบบนี้คืออะไร

**ระบบประเมินและสนับสนุนพนักงานขาย (Sales Evaluation & Enablement)** เป็นระบบภายในสำหรับทีมขาย ทำหน้าที่ 2 อย่างควบคู่กัน:

1. **ประเมินผลงานพนักงานขาย** — นำข้อมูลการขายจริงจากไฟล์ Excel เข้าระบบ เทียบกับเป้าที่ผู้จัดการตั้งไว้ แล้วสรุปออกมาเป็นตัวชี้วัด (KPI) และคะแนนรวม รายเดือน รายไตรมาส และรายปี
2. **ช่วยเหลือพนักงานขาย** — เปลี่ยนตัวเลขให้เป็นสิ่งที่นำไปทำต่อได้ ทั้ง Dashboard ส่วนตัว การเทียบกับเพื่อนร่วมทีมผ่าน Leaderboard และคำแนะนำที่ช่วยชี้จุดแข็ง/จุดที่ควรพัฒนา

ระบบไม่เชื่อมต่อกับ POS/ERP/CRM ใด ๆ — ข้อมูลการขายทั้งหมดเข้าสู่ระบบผ่านการอัปโหลดไฟล์ Excel โดยผู้จัดการ

จุดประสงค์ของระบบคือ**พัฒนายอดขายและช่วยพนักงานขายแก้จุดอ่อน** ไม่ใช่เครื่องมือคิดค่าตอบแทนหรือลงโทษ

## ใครใช้ระบบนี้บ้าง

| ผู้ใช้ | ใช้ทำอะไร |
|---|---|
| **พนักงานขาย (Salesperson)** | ดู Dashboard ของตัวเอง เทียบเป้า ดูอันดับในทีมผ่าน Leaderboard อ่านคำแนะนำจุดแข็ง/จุดที่ควรพัฒนา |
| **ผู้จัดการฝ่ายขาย (Manager)** | นำเข้าไฟล์ Excel ตั้งเป้าให้พนักงานขายแต่ละคน ดูภาพรวมทีม สั่งสร้างคำแนะนำ AI ปรับน้ำหนักคะแนน จัดการบัญชีผู้ใช้ |
| **Sales Supervisor** | พนักงานขายที่ถูกตั้งเป็นหัวหน้าของเขตใดเขตหนึ่ง — ได้สิทธิ์เพิ่มเติมเฉพาะในเขตนั้น |

ดูรายละเอียดเต็มของแต่ละบทบาทที่ [สิทธิ์การใช้งาน](/roles/)
