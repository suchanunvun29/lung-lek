# เริ่มต้นใช้งานอย่างรวดเร็ว

ภาพรวมสั้น ๆ ให้เข้าใจวิธีใช้งานหลักภายในไม่กี่นาที — รายละเอียดเต็มดูได้จากลิงก์ในแต่ละข้อ

## ถ้าคุณเป็นพนักงานขาย

1. [เข้าสู่ระบบ](/getting-started/login) — หน้าแรกที่เห็นคือ Dashboard ของคุณเอง
2. ดูยอดขายเทียบเป้าที่ [Dashboard](/features/dashboard)
3. เปิด [Leaderboard](/features/performance-leaderboard-team-overview) ดูอันดับเขตของคุณเทียบกับเขตอื่น
4. เปิด [ผลงานรายบุคคล](/features/performance-leaderboard-team-overview) เพื่อดูรายละเอียด KPI ครบและคำแนะนำ AI (ถ้าผู้จัดการสร้างไว้แล้ว)

รายละเอียด: [ดูผลงานของตัวเอง](/tasks/view-my-performance)

## ถ้าคุณเป็นผู้จัดการ

1. [เข้าสู่ระบบ](/getting-started/login)
2. ทุกเดือน: [นำเข้าข้อมูลการขายรายเดือน](/tasks/import-monthly-sales)
3. ตรวจสอบชื่อซ้ำที่ค้างอยู่ (ถ้ามี): [ยืนยันชื่อที่ซ้ำกัน](/tasks/resolve-name-duplicates)
4. ตรวจ/ปรับเป้า: [ตั้ง/แก้เป้าให้พนักงานขาย](/tasks/set-targets)
5. สั่งสร้างคำแนะนำให้คนที่ต้องการความช่วยเหลือ: [สั่งสร้างคำแนะนำ AI](/tasks/generate-ai-coaching)
6. เปิดรายงานไปใช้คุยประเมิน: [Export รายงาน](/tasks/export-reports)

รายละเอียดครบของทุกขั้นตอนรายเดือน: [รอบนำเข้าข้อมูลประจำเดือน](/workflows/monthly-import-cycle)

## ทำความเข้าใจสิทธิ์ของคุณ

สิ่งที่คุณเห็นและทำได้ในระบบขึ้นกับบทบาทของคุณ — ดู [สิทธิ์การใช้งาน](/roles/) เพื่อไม่ให้สับสนว่าทำไมบางหน้าจอ/ปุ่มไม่ปรากฏ
