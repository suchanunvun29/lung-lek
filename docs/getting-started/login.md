# การเข้าสู่ระบบ

## เข้าสู่ระบบ

1. เปิดหน้า Login
2. กรอกอีเมลและรหัสผ่านที่ผู้จัดการสร้างให้
3. กดเข้าสู่ระบบ

ระบบไม่เปิดให้สมัครบัญชีเอง — **ผู้จัดการเป็นผู้สร้างบัญชีให้ทุกคน** ผ่านหน้า [จัดการผู้ใช้งาน](/features/settings-and-users#จัดการผู้ใช้งาน-users)

📷 Screenshot Required: หน้าจอเข้าสู่ระบบ

## เปลี่ยนรหัสผ่านครั้งแรก

หากบัญชีของคุณถูกสร้างใหม่หรือถูกรีเซ็ตรหัสผ่านโดยผู้จัดการ ระบบจะ**บังคับให้เปลี่ยนรหัสผ่านก่อน** ถึงจะใช้งานหน้าอื่นได้ — คุณจะถูกพาไปหน้า "เปลี่ยนรหัสผ่าน" โดยอัตโนมัติหลังล็อกอิน และจะเข้าหน้าอื่นในระบบไม่ได้จนกว่าจะเปลี่ยนเสร็จ

หลังเปลี่ยนรหัสผ่านสำเร็จ ระบบจะพาไปที่ [Dashboard](/features/dashboard) ของคุณเอง

## เปลี่ยนรหัสผ่านภายหลัง

ไปที่เมนู **บัญชีของฉัน** (`/account`) เพื่อดูโปรไฟล์และเปลี่ยนรหัสผ่านได้ทุกเมื่อ

## ⚠️ ต้องตรวจสอบเพิ่มเติม

- ระบบยืนยันตัวตนด้วยอีเมล + รหัสผ่าน (JWT ฝั่งเซิร์ฟเวอร์) — ไม่มีการล็อกอินผ่านผู้ให้บริการภายนอก (Google/Microsoft ฯลฯ) ในโค้ดปัจจุบัน
