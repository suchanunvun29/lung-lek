# คู่มือการใช้งาน — ระบบประเมินและสนับสนุนพนักงานขาย

ระบบภายในสำหรับติดตามยอดขาย ตั้งเป้า คำนวณ KPI และช่วยพนักงานขายพัฒนาตัวเอง

ใหม่กับระบบนี้? เริ่มที่ [ระบบนี้คืออะไร](/getting-started/overview) หรือ [เริ่มต้นใช้งานอย่างรวดเร็ว](/getting-started/quick-start)

## คุณต้องการทำอะไร?

<div class="task-grid">

- **[ดูผลงานของตัวเอง](/tasks/view-my-performance)**
  เปรียบเทียบยอดขาย เป้า และคะแนน KPI ของฉันเอง

- **[นำเข้าข้อมูลการขายรายเดือน](/tasks/import-monthly-sales)**
  อัปโหลดไฟล์ Excel ยอดขายเดือนใหม่ (ผู้จัดการ)

- **[ตั้ง/แก้เป้าให้พนักงานขาย](/tasks/set-targets)**
  กำหนดเป้ารายเดือนหรือปรับเป้าที่มีอยู่แล้ว (ผู้จัดการ)

- **[ยืนยันชื่อที่ซ้ำกัน](/tasks/resolve-name-duplicates)**
  จัดการชื่อโรงพยาบาล/พนักงานขายที่สะกดต่างกัน (ผู้จัดการ)

- **[จัดการเขตและ supervisor](/tasks/manage-territories)**
  สร้างเขต มอบหมายผู้ดูแล ย้ายโรงพยาบาลเข้าเขต

- **[สั่งสร้างคำแนะนำ AI](/tasks/generate-ai-coaching)**
  ให้ระบบช่วยสรุปจุดแข็ง/จุดที่ควรพัฒนาให้พนักงานขาย

- **[Export รายงาน](/tasks/export-reports)**
  ดาวน์โหลดรายงานไปใช้ในที่ประชุมประเมินผล

</div>
